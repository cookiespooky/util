# Утилитсервис — корпоративный сайт

Статический многостраничный сайт на Markdown и [Notepub](https://github.com/cookiespooky/notepub). Публичная версия собирается GitHub Actions и размещается на GitHub Pages.

## Публичный адрес

https://cookiespooky.github.io/util/

## Что внутри

- `content/` — тексты страниц с frontmatter и `[[wikilinks]]`;
- `theme/` — HTML-шаблоны, CSS, JavaScript и компонентный слой;
- `theme/components/` — целевая структура серверных компонентов;
- `theme/assets/design-tokens.css` — единые дизайн-токены;
- `theme/assets/primitives.css` — контейнеры, секции, сетки, карточки, кнопки, формы и `.prose`;
- `docs/PAGE-INVENTORY.md` — карта типов страниц и компонентная матрица;
- `docs/BLOCK-CONTRACT.md` — контракт семантических Markdown-блоков и компонентов;
- `docs/STAGE-2-CONTENT-ACCEPTANCE.md` — состав и фиксация результата этапа 2;
- `rules.yaml` — типы страниц, маршруты, граф ссылок, поиск и sitemap;
- `config.yaml` — production-конфигурация GitHub Pages;
- `config.dev.yaml` — локальная конфигурация;
- `CONTENT-GLOSSARY.md` — единый словарь терминов и правила публичных формулировок;
- `CONTENT-SPEC.md` — структура меню, CTA, формы, заглушки и доверительные блоки;
- `scripts/build.sh` — воспроизводимая проверка и статическая сборка;
- `scripts/deploy.sh` — сборка, коммит и push текущей ветки;
- `.github/workflows/pages.yml` — автоматический деплой GitHub Pages.

## Архитектурный принцип

Markdown хранит содержание и семантику, но не задаёт CSS-сетку. Страницы переводятся на цепочку:

```text
Markdown → семантические блоки → модель страницы → серверные компоненты → HTML
```

Для контентных разделов обычный Markdown продолжает выводиться через `.prose` внутри компонентных шаблонов.

## Локальная сборка

Требуется Go 1.22+ либо готовый бинарник `notepub` в `PATH`.

```bash
./scripts/build.sh
```

Скрипт:

1. устанавливает зафиксированную версию Notepub, если бинарника нет;
2. проверяет frontmatter, маршруты, wikilinks и Markdown;
3. строит индекс;
4. собирает `dist/`;
5. проверяет наличие обязательных файлов и локальные ссылки.

## Локальный просмотр

```bash
notepub serve --config ./config.dev.yaml --rules ./rules.yaml
```

Открыть http://127.0.0.1:8080/.

## Деплой

```bash
./scripts/deploy.sh "Update site content"
```

После push workflow автоматически пересобирает и публикует сайт.
